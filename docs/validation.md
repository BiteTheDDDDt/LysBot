# 本轮验证记录

日期：2026-11-07。范围：LysBot 首版整理的本地验证；没有切换现有生产服务。公开仓库由维护者创建于 [BiteTheDDDDt/LysBot](https://github.com/BiteTheDDDDt/LysBot)，远端 CI 状态以该仓库的 Actions 为准。

## 已验证

- Windows / Python 3.13：680 项隔离测试通过。
- Linux / Python 3.13 干净依赖环境：680 项隔离测试通过。
- 真实启动 LysBot 进程，以本地模型桩和模拟 OneBot 完成群消息、规划、工具调用及回复闭环。只配置通用模型，四次调用均使用同一 general 模型；没有暴露未配置的搜索、语音或生图工具。
- 临时扩展实际加载，master 工具实际执行；普通用户不可见且执行时被权限拒绝。私聊通知收件人固定为 master。
- 固定 BGE 工件通过哈希校验，Windows 和 Linux 的真实 CPU 推理均返回 512 维向量，测试中的相关文本相似度高于无关文本。权重未加入源码仓库。
- wheel 构建及安装通过，脱离 checkout 可以导入公共 API 并找到默认磷叶石人设。
- 从 Python 基础镜像完成依赖冷构建；当前源码及 wheel 在该干净依赖环境中安装和验证，本地镜像为 `lysbot:local`。后续调整的 Dockerfile 依赖缓存布局通过 `docker build --check`，依赖提取／安装命令也在容器中检查通过。
- Compose 配置有效，不挂载 Docker socket，不默认依赖本机代理或 CLIProxyAPI。
- 新增诊断与 NapCat 操作脚本通过模拟接口测试，包括认证、二维码私有保存、保留其他连接、幂等修改与写入后回读。诊断不回显凭据，不调用模型；权重缺失时报告关键词仍可用。
- 发布检查未触发现有规则；与当前生产配置中的凭据值做精确比对，源码中无匹配。文档本地链接及 Git 空白检查通过。

## 验证边界

- 没有登录真实 QQ，也没有对真实群发送测试消息。模拟 OneBot 不代表所有 NapCat 版本均已验证。
- NapCat WebUI 后端自动接入依据当前上游接口实现，仍需在一次真实扫码部署中验证；异常会明确返回失败，不冒充接通成功。
- 没有请求真实模型供应商，未验证真实账号额度、模型可用性或回答效果。
- GitHub CI 已配置 Linux / Windows 与 Python 3.11 / 3.13，尚未在远端执行。
- 没有对生产数据库执行迁移；实际切换仍应按 `migration.md` 先验证独立副本。
- 发布检查不是完整历史密钥扫描或素材授权认定。新仓库未复制旧 Git 历史，头图的参考来源及权利边界另见 `assets/README.md`。
