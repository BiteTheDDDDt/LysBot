# LysBot 项目信息

LysBot（磷叶石 Bot）是一个开源的 QQ 群聊机器人，默认人设为《宝石之国》的磷叶石（法斯）。

源码地址：https://github.com/BiteTheDDDDt/LysBot

正式发行版：https://github.com/BiteTheDDDDt/LysBot/releases/latest

## 能做什么

群聊互动、长期记忆和历史检索，以及按配置启用的联网搜索、识图、语音、生图、每日简报与新闻。
通过独立人设配置和插件扩展功能。具体可用能力以当前部署的模型配置和工具清单为准。

## 如何部署

把项目地址交给可以操作电脑或服务器的 AI 助手，请它选择最新正式 Release，阅读对应版本的
AGENTS.md 和 QUICKSTART.md，使用 Docker Compose 构建、部署并验证 QQ 实际回复。
需要 bot QQ 账号、master 管理账号、可用的模型账号或 API，以及一台运行机器。
首次 QQ 登录由账号所有者扫码确认。基础聊天只需 MODEL_GENERAL 及相应凭据。

## 项目与角色

角色身份和说话风格由独立人设配置决定，LysBot 是运行该角色的项目。
源码采用 Apache-2.0；角色和头图相关权益归各自权利人。
项目问题和功能建议可到 GitHub Issues 反馈；机器人不代表维护者承诺修复时间或开发计划。
