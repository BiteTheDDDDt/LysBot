# QQ 使用手册

在 QQ 中直接聊天、@ bot 或使用下面的命令。命令默认以 `/` 开头，群聊和私聊均可使用。**master** 指 `.env` 中 `MASTER_QQ` 指定的账号；QQ群主或群管理员身份不会自动获得 bot 的管理权限。

## 群友命令

| 命令 | 别名 | 用途 |
| --- | --- | --- |
| `/jrrp` | `/今日人品`、`/-jrrp` | 查询今日人品，结合本人上下文生成评语；模型调用失败时仍返回固定分数 |
| `/memory` | `/记忆回顾`、`/记忆卡片` | 查看当前会话中与自己相关的记忆卡片 |

记忆纠错通过自然语言发起，例如“你记错了，我现在住在杭州”“让我看看你记住了哪些关于我的事”。修改按 bot 给出的预览确认，也可要求撤销；`/memory` 本身只查看，不修改记忆。

## master 命令

| 命令 | 别名 | 用途 |
| --- | --- | --- |
| `/help` | `/帮助` | 查看 QQ 内置帮助 |
| `/status` | `/状态` | 查看当前会话模型、各角色的主备链、记忆和任务状态 |
| `/model` | `/模型` | 查看当前聊天模型和已配置的 provider |
| `/model provider:model_id` | `/模型 provider:model_id` | 临时切换当前群聊或私聊的聊天模型 |
| `/summary` | `/摘要`、`/查看摘要`、`/统计` | 查看当前会话的近期消息、摘要和重要信息数量 |
| `/summary detail` | 参数也支持 `详细`、`full`、`完整` | 查看摘要和重要信息详情；群内触发时通过私聊发给 master |
| `/usage [窗口] [global]` | `/用量`、`/token统计` | 查看模型调用、token、延迟、失败和 fallback 统计 |
| `/clear` | `/清空`、`/清除记忆` | 重置当前会话的短期对话，保留可检索历史、摘要和人物记忆 |
| `/clear all confirm` | `/清空 全部 确认` | 清空当前会话的历史、摘要及人物记忆，不可撤销 |
| `/meme` 或 `/meme stats` | 无 | 查看图库分类数量和最近入库图片 |
| `/meme forget <id>` | 无 | 删除指定图库条目，ID 从 stats 结果取得 |
| `/meme prune` | 无 | 按配置的分类容量上限淘汰超额图片 |

### 切换模型

```text
/model
/model cliproxyapi:gpt-6-luna
/status
```

`/model` 仅设置当前会话的聊天模型覆盖，不改 `.env`、planner 或其他群的配置；重启 bot 后恢复配置默认值。provider 必须已有凭据。持久的模型候选链在 `.env` 配置，见 [候选链与自动 fallback](configuration.md#候选链与自动-fallback)。

### 查询用量

```text
/usage
/usage 7d
/usage global 30d
```

默认查看当前群聊或私聊最近 24 小时，窗口支持 `24h`、`7d`、`30d`、`all`。加 `global`（也支持 `g`、`全局`）查看整个实例。token 及调用记录来自接口返回，实际费用以服务商账单为准。

### 查看与清理数据

`/summary detail` 是查看已有摘要，不会立即生成新的每日简报。群内使用时，bot 需要能向 master 发私聊消息。

`/clear` 和 `/clear all confirm` 都作用于发命令的当前会话。群内执行影响整个当前群，私聊执行只影响该私聊；完整清理无法通过记忆纠错的撤销恢复。

图库管理示例：先用 `/meme stats` 查看条目，再按需执行 `/meme forget 123`。`/meme prune` 是否淘汰图片取决于容量配置，上限为不限时不会因此清理图片。

## 日常使用与维护

简报和新闻由配置开关、时间控制，配置见 [配置手册](configuration.md)。人设、模型链和功能开关的修改可以直接交给部署 AI；运行诊断与维护入口见 [AI 操作说明](ai-operations.md)。
